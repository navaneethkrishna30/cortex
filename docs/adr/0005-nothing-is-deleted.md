# Nothing is deleted: forgetting is a move to .archive/

No tool deletes a note. To forget, a note moves to `.archive/`, which is never searched but still opens by path; a changed fact is superseded or updated, so the old version stays visible in History. Agents make mistakes, and with no old versions (ADR 0004) a delete could not be undone. The vault grows a little, which is fine for one person's notes.
