# Relation types

Add new ones deliberately, when a real need appears.

| Relation | Meaning | Example |
|---|---|---|
| `part_of` | belongs to a larger thing | a feature is part_of a project |
| `depends_on` | needs another thing to work | an app depends_on a database |
| `located_in` | lives in or on something | a folder is located_in a machine |
| `uses` | uses a tool or resource | a project uses a library |
| `owned_by` | belongs to a person | a task is owned_by someone |
| `replaces` | newer version of something | a new plan replaces an old one |
